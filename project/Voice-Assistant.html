💻 Yêu Cầu Hệ Thống

  • Windows 10 trở lên
  • Python 3.11 hoặc mới hơn
  • Micrô hoạt động bình thường
  • Kết nối Internet (cho nhận dạng giọng nói và TTS)

📥 Cài Đặt

Bước 1: Clone Repository

git clone https://github.com/hongphong214365/Voice-Assistant.git cd Voice-Assistant

Bước 2: Cài Đặt Thư Viện Phụ Thuộc

Sử dụng uv (Được khuyến nghị):

uv sync

Hoặc sử dụng pip:

pip install -r requirements.txt

Bước 3: Chạy Trợ Lý

uv run main.py

Hoặc:

python main.py

🚀 Cách Sử Dụng

Ví Dụ Nhanh

Khi chạy chương trình, bạn sẽ nhìn thấy:

Chào bạn, tôi đã sẵn sàng.

Nói lệnh của bạn:

  • Nói: "Mấy giờ rồi?"
    Phản hồi: "Bây giờ là 17 giờ 5 phút"
  • Nói: "Mở Google"
    Phản hồi: "Đã mở google" (Trình duyệt sẽ mở)
  • Nói: "Tạm biệt"
    Phản hồi: "Tạm biệt bạn, cần giúp gì thì nói mình nhé" (Thoát)

⚙️ Cấu Hình Ngôn Ngữ

Mở file config.py và thay đổi:

# Tiếng Việt LANG = "vi-VN" # Tiếng Anh LANG = "en-US"

Rồi khởi động lại chương trình.

🎯 Các Lệnh Hỗ Trợ

🎤 Xin Chào (Greeting)

Người dùng: "Xin chào" / "Hello"

Trợ lý: Chào bạn / Hello
👤 Hỏi Tên (Ask Name)

Người dùng: "Bạn tên gì?" / "What's your name?"

Trợ lý: Tôi là trợ lí ảo của bạn / I am your virtual assistant
⏰ Hỏi Giờ (Ask Time)

Người dùng: "Mấy giờ rồi?" / "What time is it?"

Trợ lý: Bây giờ là 17 giờ 5 phút / It is 17:05
📅 Hỏi Ngày (Ask Date)

Người dùng: "Hôm nay là ngày mấy?" / "What's today's date?"

Trợ lý: Hôm nay là ngày 15 tháng 6 năm 2026 / Today is June 15, 2026
🌐 Mở Website

Người dùng: "Mở Google" / "Mở YouTube" / "Mở GitHub"

Trợ lý: Đã mở google (Trình duyệt sẽ mở website)
📱 Mở Ứng Dụng

Người dùng: "Mở Notepad" / "Mở Máy Tính" / "Mở File Explorer"

Trợ lý: Đã mở notepad (Ứng dụng sẽ khởi động)
🔇 Tạm Dừng Nghe

Người dùng: "Tạm dừng nghe" / "Stop listening"

Trợ lý: Đã dừng nghe, ấn phím tắt để tiếp tục
👋 Thoát (Exit)

Người dùng: "Tạm biệt" / "Bye" / "Kết thúc"

Trợ lý: Tạm biệt bạn, cần giúp gì thì nói mình nhé (Chương trình thoát)

🔧 Xử Lý Sự Cố

❌ Lỗi: No module named 'speech_recognition'

Giải pháp:

uv add SpeechRecognition

Hoặc:

pip install SpeechRecognition
❌ Lỗi: No module named 'sounddevice'

Giải pháp:

pip install sounddevice
❌ Lỗi: Permission denied: audio/Voice.mp3

Nguyên nhân: Tệp âm thanh vẫn đang được sử dụng.

Giải pháp: Đảm bảo pygame đã phát xong tệp trước khi xóa hoặc tạo lại.

❌ Lỗi: UnknownValueError

Nguyên nhân: Trình nhận dạng không hiểu được âm thanh.

Giải pháp:

  • Nói rõ ràng hơn
  • Giảm tiếng ồn xung quanh
  • Tăng thời lượng ghi âm
