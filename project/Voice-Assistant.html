⏰ Đọc giờ & ngày

Hỏi giờ, hỏi ngày — trợ lý trả lời bằng giọng nói.

🌐 Đa ngôn ngữ (VN / EN)

Hỗ trợ Tiếng Việt và Tiếng Anh (tiếng Anh còn hạn chế).

🔗 Mở Website & Ứng dụng

Mở trang web hoặc chương trình theo danh sách trong data/*.json — dễ chỉnh sửa.

🔧 Tùy chỉnh bằng JSON

Danh sách website và ứng dụng có thể chỉnh trong data/websites.json và data/apps.json.

📥 Cài Đặt & Chạy Nhanh

Clone repo, cài phụ thuộc và chạy:

git clone https://github.com/hongphong214365/Voice-Assistant.git cd Voice-Assistant # Khuyến nghị dùng uv uv venv uv sync uv run main.py # hoặc pip tiêu chuẩn pip install -r requirements.txt python main.py

🎯 Các Lệnh Cơ Bản

Xin chào
Người dùng: "xin chào" — Trợ lý: "Chào bạn"
Hỏi tên
Người dùng: "bạn tên gì" — Trợ lý: "Tôi là trợ lí ảo của bạn"
Hỏi giờ / ngày
Người dùng: "mấy giờ rồi?" — Trợ lý đọc giờ hiện tại
Mở website / ứng dụng
Người dùng: "mở google" — Trợ lý sẽ mở website tên google bằng trình duyệt theo cấu hình
Tạm dừng nghe
Người dùng: "tạm dừng nghe" — Trợ lý tạm dừng (không thoát). Nhấn Ctrl+Alt+A để tiếp tục.
Thoát
Người dùng: "tạm biệt" — Trợ lý xác nhận và thoát chương trình.

🔊 Yêu Cầu Âm Thanh

Khi muốn đổi hiệu ứng âm thanh, xem thêm tài liệu chi tiết.

  • Định dạng: WAV
  • Tên file phải khớp với cấu hình (ví dụ: START_SOUND.wav)
  • Sample rate: 44100 Hz
