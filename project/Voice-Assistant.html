🎤 Voice Assistant

Trợ lý giọng nói nhỏ gọn viết bằng Python — đọc giờ/ngày, trả lời tiếng Việt & tiếng Anh (còn hạn chế), mở website và ứng dụng theo cấu hình JSON.

Xem trên GitHub Xem README Báo lỗi / Góp ý

✨ Tính Năng chính

⏰ Đọc giờ & ngày

Hỏi giờ, hỏi ngày — trợ lý trả lời bằng giọng nói hoặc văn bản.

🌐 Đa ngôn ngữ (VN / EN)

Hỗ trợ Tiếng Việt và Tiếng Anh (tiếng Anh còn hạn chế).

🔗 Mở Website & Ứng dụng

Mở trang web hoặc chương trình theo danh sách trong data/*.json — dễ chỉnh sửa.

🔧 Tùy chỉnh bằng JSON

Danh sách website và ứng dụng có thể chỉnh trong data/websites.json và data/apps.json.

📥 Cài đặt & Chạy nhanh

Clone repo, cài phụ thuộc và chạy:

git clone https://github.com/hongphong214365/Voice-Assistant.git
cd Voice-Assistant
# Khuyến nghị
uv sync
uv run main.py
# hoặc
pip install -r requirements.txt
python main.py

🎯 Các lệnh cơ bản

Xin chào
Người dùng: “xin chào” — Trợ lý: “Chào bạn”
Hỏi tên
Người dùng: “bạn tên gì” — Trợ lý: “Tôi là trợ lí ảo của bạn”
Hỏi giờ / ngày
Người dùng: “mấy giờ rồi?” — Trợ lý đọc giờ hiện tại
Mở website / ứng dụng
Người dùng: “mở google” — Trợ lý sẽ mở trình duyệt theo cấu hình
Tạm dừng nghe
Người dùng: “tạm dừng nghe” — Trợ lý tạm dừng (không thoát). Nhấn Ctrl+Alt+A để tiếp tục.
Thoát
Người dùng: “tạm biệt” — Trợ lý xác nhận và thoát chương trình.

🔊 Yêu cầu âm thanh (khi dùng file)

  • Định dạng: WAV
  • Tên file phải khớp với cấu hình (ví dụ: record.wav)
  • Sample rate: 44100 Hz

⚠️ Lưu ý

Hiện tại bot vẫn đang trong giai đoạn phát triển và chạy trong terminal — chưa có giao diện đồ họa (UI). Có thể còn lỗi hoặc các hành vi chưa mong muốn.

Nếu gặp vấn đề, vui lòng báo lỗi tại: Issues.

Trang này ưu tiên cung cấp thông tin ngắn gọn cho người muốn cài/dùng. Thông tin chi tiết hơn (tài liệu kỹ thuật, hướng dẫn sâu) có trong README.

Đã tối ưu văn bản cho trình đọc NVDA; bố cục và style dùng lại file style.css của trang chính để đảm bảo tương phản và truy cập.
