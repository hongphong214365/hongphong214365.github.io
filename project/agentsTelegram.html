📝 Giới Thiệu Chi Tiết

AgentsTelegram là một bot Telegram viết bằng Python để gửi lệnh và chạy script trên máy tính của bạn từ xa. Mục tiêu: tự động hóa tác vụ, kiểm thử nhanh và quản lý script qua chat.

✨ Tính Năng Chính

🤖 Thực Thi Script

Nhận lệnh qua Telegram và thực thi các script Python từ xa một cách nhanh chóng.

📤 Phản Hồi Kết Quả

Gửi kết quả đầu ra (output) hoặc thông báo lỗi trực tiếp về kênh Telegram của bạn.

🔒 Bảo Mật An Toàn

Hạn chế quyền truy cập vào một tài khoản Telegram cụ thể bằng Token và Admin ID.

⚙️ Cấu Hình Dễ Dàng

Dễ dàng cấu hình bot bằng các biến môi trường đơn giản.

💻 Điều Kiện Tiên Quyết

  • Python phiên bản 3.10 trở lên.
  • Tài khoản Telegram cá nhân.
  • Telegram Bot Token (lấy từ @BotFather).

📥 Hướng Dẫn Cài Đặt

  1. Clone Repository: Sao chép kho mã nguồn về máy:
    git clone https://github.com/hongphong214365/agentsTelegram.git cd agentsTelegram
  2. Tạo Môi Trường và Cài Đặt Phụ Thuộc:

    Khuyến nghị dùng uv:

    uv venv && uv sync

    Hoặc dùng Python tiêu chuẩn:

    python -m venv .venv # Trên Windows: .venv\Scripts\activate # Trên Linux/macOS: source .venv/bin/activate pip install -r requirements.txt
  3. Thiết Lập Biến Môi Trường:

    Bạn bắt buộc phải nhập chính xác tên biến môi trường TELEGRAM_TOKEN và TELEGRAM_ADMIN_ID thì bot mới có thể xác thực và hoạt động.

    Trên Windows (CMD):

    set TELEGRAM_TOKEN=your_token_here set TELEGRAM_ADMIN_ID=your_id_here

    Trên Linux / macOS:

    export TELEGRAM_TOKEN="1234567890:AAExampleTokenHere" export TELEGRAM_ADMIN_ID="123456789"
  4. Khởi Chạy Bot:

    Sử dụng uv:

    uv run main.py

    Hoặc sử dụng Python tiêu chuẩn:

    python main.py

🧪 Kiểm Tra Hoạt Động

Nếu cấu hình đúng, khi chạy bot bạn sẽ thấy thông báo:

agentsTelegram started successfully.

Bạn có thể kiểm tra bằng cách gửi lệnh cho bot:

📡 Gửi Lệnh /ping

Người dùng gửi: /ping

Kết quả mong đợi: online

Lưu ý: Hầu hết các lệnh điều khiển hệ thống hiện tại đều yêu cầu quyền Admin (phải khớp với TELEGRAM_ADMIN_ID đã cấu hình).
