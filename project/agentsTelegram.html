AgentsTelegram

Bot Telegram cho phép chạy file Python từ xa an toàn và có thể mở rộng.

Giới thiệu chi tiết

AgentsTelegram là một bot Telegram viết bằng Python để gửi lệnh và chạy script trên máy tính của bạn từ xa. Mục tiêu: tự động hóa tác vụ, kiểm thử nhanh và quản lý script qua chat.

Tính năng chính

  • Nhận lệnh qua Telegram và thực thi script Python.
  • Gửi kết quả đầu ra hoặc lỗi về kênh telegram.
  • Hạn chế quyền truy cập vào một tài khoản telegram cụ thể bằng token và admin ID.
  • Dễ dàng cấu hình bằng các biến môi trường.

Điều kiện tiên quyết

  • Python phiên bản 3.10 trở lên.
  • Tài khoản Telegram cá nhân.
  • Telegram Bot Token (lấy từ @BotFather).

Hướng dẫn nhanh

  1. Sao chép kho về máy: git clone <repo>
  2. Tạo môi trường và cài đặt phụ thuộc:
    Khuyến nghị dùng uv: uv venv && uv sync
    Hoặc dùng Python tiêu chuẩn: python -m venv .venv && pip install -r requirements.txt
  3. Thiết lập biến môi trường:

    Trên Windows (CMD):

    set TELEGRAM_TOKEN=your_token_here
    set TELEGRAM_ADMIN_ID=your_id_here

    Trên Linux / macOS:

    export TELEGRAM_TOKEN="1234567890:AAExampleTokenHere"
export TELEGRAM_ADMIN_ID="123456789"

    Lưu ý: Bạn bắt buộc phải nhập chính xác tên biến môi trường TELEGRAM_TOKEN và TELEGRAM_ADMIN_ID thì bot mới có thể xác thực và hoạt động.

  4. Chạy bot: uv run main.py hoặc python main.py

Kiểm tra hoạt động

Nếu cấu hình đúng, khi chạy bot bạn sẽ thấy thông báo: agentsTelegram started successfully.

Bạn có thể kiểm tra bằng cách gửi lệnh cho bot:

  • Gửi /ping -> Kết quả mong đợi: online

Lưu ý: Hầu hết các lệnh điều khiển hệ thống hiện tại đều yêu cầu quyền Admin (phải khớp với TELEGRAM_ADMIN_ID đã cấu hình).
